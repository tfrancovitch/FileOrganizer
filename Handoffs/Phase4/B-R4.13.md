## Questions
1. **Shared folders.** Inside one OneDrive root, how does a local process tell that a folder is shared with other people (owned by this account, shared out), and that a folder is a shared folder *from someone else* added by "Add shortcut to My files" (older: "Add to my OneDrive")? Candidates: a reparse tag or attribute; a shell property (`System.StorageProviderShareStatuses`, `System.StorageProviderState`); `CfGetPlaceholderInfo` / custom states; `CfGetSyncRootInfoByPath` differences; a registry trace; the `desktop.ini`. Which work without admin, from Python, without opening file content? What does a move of a file *into* or *out of* such a folder do to the other people's access, per Microsoft's own pages?
2. **Personal Vault.** How is the Vault represented locally when locked and when unlocked (a reparse point? a mounted BitLocker virtual drive, hence a different volume serial? a junction?). Does the `same_volume` check (volume serial from `FileIdInfo`) already refuse a move into or out of it? What happens to a file renamed inside it while unlocked, when it relocks?
3. **OneDrive's own naming rules.** The current list of names and characters OneDrive refuses or renames (reserved names, `~$` prefix, `_vti_`, `.lock`, `desktop.ini`, leading/trailing spaces, path length limit for the sync client), with the Microsoft page and date. Which of these are *not* already refused by Windows naming rules, so that a rename Windows accepts becomes a sync error?
4. **Pin-state inheritance.** What exactly does a file inherit when renamed into another folder inside a sync root (PINNED, UNPINNED, "online-only folder" defaults)? Does inheritance trigger a download or a dehydration? Is `FileRenameInformationEx` with `FILE_RENAME_SUPPRESS_PIN_STATE_INHERITANCE` available from `SetFileInformationByHandle(FileRenameInfoEx)` on Windows 11, and should the product use it, or refuse moves between folders whose pin state differs?
5. **What OneDrive does with a raw rename.** For a rename or intra-root move performed by `SetFileInformationByHandle` (not Explorer): does the cloud keep the item identity, version history and share links; what happens if OneDrive is paused, offline or signed out at the time; how long until convergence; can convergence be observed locally (the `IN_SYNC` state, a shell property, the activity log)? Mark untested where Microsoft is silent.
6. **Visible quarantine folder.** For D7(a): any OneDrive behaviour that would make a visible top-level folder named `_FileOrganizer-Quarantine`, holding files moved into it by rename, behave differently from an ordinary folder (name rules, "Files On-Demand" defaults for new folders, Known Folder Move specifics for `Documents`).
