## 9. Judgment calls (flag these)

1. **Offline roots now block, and Phase 1 re-probes roots every run** (§3).
   Without these the guard cannot tell offline from renamed. The consequence: after
   a root is renamed away, the old root's last-known files stay in their groups
   and those groups stay Blocked -- **a root cannot be removed from a project**
   (nothing sets `source_root.is_active = 0`). Reported as a pre-Phase 4 item; not
   built (it is Phase 1 scope).
2. **`sequence` still comes from the row id.** Decisions and review events are
   append-only, so the rowid *is* the append order; the loader derives `sequence`
   from it in one place and nothing else orders by an id (ARCHITECTURE.md
   "Identifiers and order"). A dedicated column would need a migration; the
   relabelling test holds sequence fixed and permutes every id.
3. **`no_dangling_protection` is attached, not declared on every removal** -- like
   B17's overlap warning, so a plan with no dangling protection is byte-for-byte
   B18's and no fingerprint moves. `EVALUATOR_VERSION` and `REGISTRY_VERSION` went
   to `/2`.
4. **Its result is `unknown`, not `fail`** -- the handoff's "unknown never passes":
   the item is `blocked_evidence`.
5. **A locked revision with a ready removal goes obsolete when a protection
   dangles** (`protection_dangling`) -- not asked for; every removal's
   `target_not_protected` read every protection policy, so they are its
   dependencies.
6. **Mount points** as Phase 1 actually treats them (§3).
7. **Five gates narrowed** so the schema could state them (§9 Q3). No stored value
   changed.
8. **Re-pointing to a scope that also matches nothing** is allowed after a
   confirmation (a person may re-point before the next scan).
9. **The suggestion needs identity and place**: the same volume serial + file index
   at a path that keeps the file's relative path under the scope. A hard link
   elsewhere with the same relative path would look like a move -- it is labelled a
   suggestion and never applied without the person (closeout §6).
10. **The lab manifest's README entry re-hashed** (§4).
11. **`jsonschema` is listed as optional in `Install-Dependencies.ps1`**, so the
    startup check installs it when missing, although only a test suite uses it.
12. **The scope facts are cached** per database and evidence mark (a scan moves
    it); never authoritative.

"""Archive the root docs (synced from phase3-b17) and replace them with the
